# Architectuur

We beschrijven de architectuur van PLUGIN in het [arc42](https://arc42.org) framework. Dit framework bevat 12 onderdelen:

1. Inleiding en doelen
2. Randvoorwaarden
3. Context en scope
4. Oplossing
5. Overzicht van bouwstenen
6. Overzicht van _runtime_
7. Overzicht van implementatie
8. Concepten
9. Architectuur besluiten
10. Kwaliteit
11. Risico en technische schuld
12. Woordenlijst
